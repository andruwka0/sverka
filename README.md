# Сверка связей

Веб-приложение для сравнения участников процедур и близких лиц сотрудников. Принимает три Excel-файла и показывает совпадения телефонов, адресов и ФИО с объяснением баллов и ссылками на исходные строки.

[Открыть приложение](https://sverka.andruwka.site)

## Запуск

Нужен Python 3.12 или новее. Проверено на Python 3.14.

```sh
cd app
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn radar.main:app --host 127.0.0.1 --port 8000
```

Интерфейс — http://127.0.0.1:8000/, описание методов — http://127.0.0.1:8000/docs.

## Формат файлов

Загрузить три книги `.xlsx`, в каждой один лист данных с заголовками в первой строке.

| Файл | Столбцы |
|---|---|
| Участники | `participant_id`, `tender_id`, `company_name`, `inn`, `director_name`, `phone`, `email`, `address` |
| Сотрудники | `official_id`, `full_name`, `position`, `role_in_tender`, `tender_id` |
| Близкие лица | `official_id`, `relation_type`, `full_name`, `inn`, `phone`, `email`, `address` |

Сотрудники связываются с близкими лицами по `official_id`, с участниками — по `tender_id`. Совпадения проверяются внутри одной процедуры. Данные демонстрационного набора в `app/data/` вымышленные. CSV используют разделитель `;` и UTF-8.

Веса, пороги сходства и уровни приоритета задаются в `app/rules.yaml`. После изменения конфигурации перезапустить приложение. Телефон сравнивается после нормализации. Для адресов используется расстояние Левенштейна, для ФИО — Джаро — Винклер. Разные номера домов и корпусов, а также противоречащие инициалы исключают соответствующее совпадение.

Карточка показывает приоритет ручной проверки. В демонстрационном наборе найдена одна пара с совпавшими телефоном и адресом, сумма 80 баллов. Телефон и адрес первой таблицы относятся к участнику. Загруженные файлы и результаты не сохраняются. Отметки проверяющего действуют до новой сверки или перезагрузки страницы.

## Проверка

```sh
cd app
.venv/bin/python -m pytest -q
.venv/bin/ruff check radar tests
.venv/bin/ruff format --check radar tests
```

## Docker

```sh
docker build -t sverka ./app
docker run --rm -p 127.0.0.1:8000:8000 --read-only --tmpfs /tmp:size=64m sverka
```

Контейнер работает под UID 1000, проверка готовности — `GET /healthz`. Зависимости исполнения зафиксированы в `requirements.runtime.txt`, инструменты проверки включены в `requirements.txt`. Приложение рассчитано на небольшие таблицы, пары внутри процедуры проверяются перебором.
